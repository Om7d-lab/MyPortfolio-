# Omid Mahdizadeh — Portfolio

A personal portfolio site: plain HTML/CSS, no build step, hosted directly from
this repository root via GitHub Pages.

## Pages

- `index.html` — Home (introduction)
- `projects.html` — Projects (links out to project pages)
- `resume.html` — Resume
- `style.css` — Shared stylesheet for the portfolio pages, based on `BMZ_Design_Bible.pdf`

## Project pages

Project pages (e.g. `opensign.html`) are standalone artifacts with their own
design and are linked to from `projects.html`, not embedded or rebuilt.

## Source files

- `Omid_Mahdizadeh_Resume.docx` — original resume (also downloadable from the Resume page)
- `BMZ_Design_Bible.pdf` — design system reference used to style the portfolio pages
